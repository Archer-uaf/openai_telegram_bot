# Telegram ChatGPT Bot

A Telegram bot built with Python and integrated with OpenAI's ChatGPT.  
The bot provides several interactive commands and features.  

## ✨ Features

### Core Features
- **/start** — welcome message and navigation to the main menu  
- **/random** — returns a random fact (from a local file or generated by ChatGPT)  
- **/gpt** — ChatGPT interface: user sends a question → GPT responds  
- **/talk** — conversation with famous personalities (Einstein, Jobs, Musk)  
- **/quiz** — interactive quiz: choose a topic, answer questions, GPT evaluates  

### Extra Features
- **/translate** — text translator with language selection (EN, DE, PL, ES, UK)  
- **/recommendations** — movie recommendations by genre with options to get more suggestions

## 🛠️ Tech Stack

- Python 3.10+  
- [python-telegram-bot](https://docs.python-telegram-bot.org/)  
- [OpenAI API](https://platform.openai.com/)  
- [python-dotenv](https://pypi.org/project/python-dotenv/)

## ⚙️ Setup

1. Clone the repository  
   git clone https://github.com/Archer-uaf/openai_telegram_bot.git
   cd openai_telegram_bot

3. Create and activate a virtual environment  
   python -m venv .venv
   source .venv/bin/activate   # Linux / Mac
   .venv\Scripts\activate      # Windows

4. Install dependencies  
   pip install -r requirements.txt

5. Create a `.env` file in the project root with your keys:  
   OPENAI_API_KEY=your_openai_api_key
   TG_BOT_API_KEY=your_telegram_bot_api_key

6. Run the bot  
   python -m src.app.bot
